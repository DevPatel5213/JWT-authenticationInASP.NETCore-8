# JWT Authentication API in ASP.NET Core 8

This project is a **backend Web API** that demonstrates **JWT (JSON Web Token) authentication** in **ASP.NET Core 8**.  
It uses **ASP.NET Core Identity**, **Entity Framework Core**, and JWT bearer tokens to secure API endpoints.

---

## 📌 **Features**

- ✅ User registration & login with ASP.NET Core Identity
- ✅ JWT bearer token generation & validation
- ✅ Entity Framework Core with SQL Server
- ✅ CORS support to connect with an external frontend (e.g., Angular, React, etc.)
- ✅ Swagger UI with JWT authorization support
- ✅ Clean and simple `Program.cs` configuration

---

## ⚙️ **Tech Stack**

- ASP.NET Core 8 Web API
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- JWT (JSON Web Token)
- Swagger (OpenAPI)
